## 📚 About the Repository

Computer Graphics is a field of computer science that deals with the creation, manipulation, and representation of images and graphical objects using computers.

This repository covers practical implementations of important Computer Graphics concepts such as:

* Graphics programming
* Line drawing algorithms
* Geometric transformations
* 2D and 3D graphics concepts
* Clipping algorithms
* Curve and shape generation
* Animation and multimedia concepts
* Other Computer Graphics algorithms and practical exercises

# 🧪 Lab 2

### Topic

**DDA (Digital Differential Analyzer) Line Drawing Algorithm**

Lab 2 implements the DDA Line Drawing Algorithm using C++ and a graphics library.

The program:

1. Accepts the starting point `(x1, y1)`.
2. Accepts the ending point `(x2, y2)`.
3. Calculates `dx` and `dy`.
4. Calculates the required number of steps.
5. Calculates the x and y increments.
6. Plots the line pixel-by-pixel.
7. Displays the graphical output.

📁 **Folder:** `Lab2`
