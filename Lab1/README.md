# CGM Lab Assignment – 1
## Basic Graphics Primitives using C++ and WinBGIm

---

## Aim

To write C++ programs using the `graphics.h` (WinBGIm) graphics library to draw basic graphics primitives.

---

## Learning Objective

The objective of this lab is to understand and implement basic graphics primitives using C++ and the WinBGIm graphics library.

The following graphics primitives are implemented:

- Straight Line
- Circle
- Rectangle
- Triangle

---

## Software and Tools Used

- **Programming Language:** C++
- **Graphics Library:** WinBGIm
- **Header File:** `graphics.h`
- **Compiler:** MinGW / GCC
- **IDE:** AntiGravity IDE
- **Operating System:** Windows
